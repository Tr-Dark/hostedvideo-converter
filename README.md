# HostedVideo converter

Статична сторінка українською для підготовки Membrana embed-коду до вставки у HostedVideo.

Без залежностей, зборки, зовнішніх скриптів, аналітики чи передачі вставленого коду на сервер. Основна функція — `convertEmbed()` у `converter.js`.

1. Вставте повний embed-код.
2. Натисніть «Підготувати код», потім «Скопіювати код».
3. Створіть новий HostedVideo й вставте через звичайний Ctrl+V / Cmd+V.

Парсер перевіряє JSON, наявність обкладинки, MP4, containerId, videoParams та adParams. Формує порядок атрибутів і закінчення `push(...)`, які очікує поточний конвертер HostedVideo, та екранує кутові дужки для обробника вставки. Уже екранований результат можна обробити повторно.

Це обхід для поточного обробника TinyMCE у `redesign`, а не універсальний формат відеовставки. Після виправлення обробника в адмінці цей обхід слід переглянути. Збереження у живій адмінці потрібно перевірити окремо.
